# 0016 — Contract split: portable template + dev doc + generated AGENTS.md

- **Status:** 🟢 Accepted
- **Date:** 2026-06-12
- **Spec:** [contract-split](../specs/2026-06-12-contract-split.md) · ROADMAP Phase 10

## Context

`AGENTS.md` conflated two concerns: the portable operating contract (gate sequence, conduct rules, memory protocol) that belongs to every agent operating under Topology, and framework-dev conventions (Rust/Bash stack, skill house format) that concern only contributors to the framework repo itself. Skills shipped in the payload hardcoded `docs/<kind>/` artifact paths that are wrong for governed projects whose artifacts root is `.claude/topology/`.

## Decision

1. **`templates/CONTRACT.template.md`** — the portable contract sections extracted from `AGENTS.md` with three placeholders: `{{ARTIFACTS_ROOT}}` (substituted as `docs` for the framework, `.claude/topology` for governed projects), `{{GATEKEEPER_CMD}}` (always `gatekeeper`), `{{BINARY_NOTE}}` (empty for framework; for governed projects one sentence stating the binary resolves through `GATEKEEPER_BIN` in `.claude/settings.json` — the wiring itself is created by Phase 9's integration). Shipped in the payload at `templates/CONTRACT.template.md`; the `CONTRACT.md` slot in the payload remains reserved for Phase 9's inject step.

2. **Fail-closed render** — `render_contract` in `adapt.rs` substitutes the three known placeholders via plain string replacement (ADR-0007 dependency freeze: no template crate). Any remaining `{{` after substitution is a hard error naming the offending placeholder. Unknown placeholders are caught by the same residual-`{{` check.

3. **`docs/DEVELOPMENT.md`** — the two framework-dev sections (stack conventions, skill house format) move here verbatim under a one-line audience preamble ("framework contributors only — never shipped"). `docs/` is payload-excluded by `build-payload.sh`; governed projects never receive this file.

4. **`AGENTS.md` is generated** — the repo dogfoods its own template: `AGENTS.md` = `render_contract(template, framework ctx)` + `FRAMEWORK_TRAILER` (a pointer to `docs/DEVELOPMENT.md`). Generated by running `gatekeeper adapt --contract framework`. An integration test asserts byte-equality — hand-edits or template drift fail `just check`.

5. **CLI surface** — `gatekeeper adapt --contract <framework|project>` renders the template and prints to stdout (exit 0); render error → message on stderr naming the offending placeholder, exit 2. Registered in the dispatch table (ADR-0014) and `check_help_or_unknown`. Delivery wiring for governed projects (`@.topology/CONTRACT.md` import, managed blocks, `GATEKEEPER_BIN`) is Phase 9 scope.

6. **Skill wording sweep** — seven skills and one plan template switch from `docs/<kind>/...` to `<artifacts-root>/<kind>/...`, with a one-line definition parenthetical at first use per skill. `skill-rules.json` untouched. No skill names, descriptions, or behaviors change.

## Phase 9 boundary

Contract **delivery** into governed projects — the `@.topology/CONTRACT.md` import line, managed blocks, `GATEKEEPER_BIN` settings wiring, and switching `build_cursor`/`build_opencode` to deliver the rendered contract when roots differ — is Phase 9 scope. Phase 10 provides the template and pure render function that Phase 9 will call.

## Consequences

- The portable contract is now testable in isolation (`render_contract` unit tests, `adapt --contract` integration tests).
- Drift between `AGENTS.md` and the template is caught automatically by the byte-equality test in CI.
- Governed projects no longer receive framework-dev conventions via any delivery path (once Phase 9 wires contract delivery).
- Skill path references are portable; agents in governed projects read the correct artifacts root from gate FAIL messages.
