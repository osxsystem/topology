# Verify — `adapt` v2: project integration (Phase 9)

- **Date:** 2026-06-12
- **Spec:** `docs/specs/2026-06-12-adapt-v2.md` · **Plan:** `docs/plans/2026-06-12-adapt-v2.md`
- **Branch:** `feat/adapt-v2` · **Binary:** `gatekeeper 0.9.0`

## Symptom (before)

On `main`, `gatekeeper adapt` v1 generated harness config but did **not** integrate a project:
`adapt --harness claude` emitted a *whole-file* `.claude/settings.json` (clobbering any user keys),
never set `GATEKEEPER_BIN`, never scaffolded `.claude/topology/`, and never delivered the operating
contract into the project's always-on surface. A review during this phase also found the first cut of
the integration left `adapt --harness claude --check` **hollow** — it early-returned before checking
the import / scaffold / contract, so a missing import reported "up to date".

## Resolution (after) — live end-to-end transcript

Fixture: a scratch framework payload (`templates/CONTRACT.template.md`, `bin/gatekeeper`) + a project
with a **pre-existing** `CLAUDE.md` (user prose) and `.claude/settings.json` (`model` + `env.MY_VAR`).

```
$ TOPOLOGY_ROOT=…/fw gatekeeper adapt --harness claude        # run in the project
wrote .claude/settings.json
wrote .claude/topology/{config.toml,research,specs,plans,verify,reviews/.gitkeep}
wrote .topology/CONTRACT.md
updated …/CLAUDE.md
```

- **CLAUDE.md** — user content intact, import appended (AC-1):
  ```
  # My Project

  User-authored content.
  @.topology/CONTRACT.md
  ```
- **settings.json** — user `model` and `env.MY_VAR` preserved; `hooks` + `env.GATEKEEPER_BIN` added
  (AC-4, AC-5): `"GATEKEEPER_BIN": "…/fw/bin/gatekeeper"`, `"MY_VAR": "keep-me"`, `"model": …`.
- **scaffold** — `.claude/topology/{research,specs,plans,verify,reviews}/` present (AC-6).
- **contract** — `.topology/CONTRACT.md` ends with the bare-stub first-session instruction (AC-7).
- **idempotency** — second `adapt` leaves `CLAUDE.md` and `settings.json` byte-identical;
  `adapt --harness claude --check` → `up to date`, exit `0`.
- **--check drift (the review fix)** — delete the import line, then `--check`:
  ```
  DRIFT …/CLAUDE.md
  check-exit: 1
  ```
- **codex managed block (AC-3)** — `adapt --harness codex` wraps a marker block in a pre-existing
  `AGENTS.md`; tampering inside the block and re-running **restores** it while user content outside
  survives. A malformed block (begin without end) → exit `2` naming the file (AC-8):
  ```
  gatekeeper adapt: '<!-- BEGIN TOPOLOGY MANAGED BLOCK -->' without '<!-- END … -->' — malformed block in …/AGENTS.md
  codex-exit: 2
  ```
