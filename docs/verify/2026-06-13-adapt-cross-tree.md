# Verify — cross-tree dogfood generation (#54)

- **Date:** 2026-06-13
- **Spec:** `docs/specs/2026-06-13-adapt-cross-tree.md` · **Plan:** `docs/plans/2026-06-13-adapt-cross-tree.md`
- **Binary:** `gatekeeper 0.10.0`

## Symptom (before)

When a `gatekeeper` binary built in one topology worktree adapts a *different* topology clone
(`framework_root → A`, `project_root → B`, `roots_differ == true`), `adapt` took the governed branch
and baked **A's absolute paths** (hooks + pinned `GATEKEEPER_BIN`) into B's `.claude/settings.json`.
Delete A → B's `PreToolUse` hook and finish gate dangle. This is the originally-logged incident
(`dogfood-settings-pinned-to-worktree`: the main clone pinned to a deleted `topology-phase12`). #50/#51
fixed only the `read_root == write_root` sub-case; this cross-tree variant — the one that caused the
real incident — was still open (tracked as #54).

Reproduced against the pre-fix code this session:

- `cross_tree_dogfood_settings_are_portable` — **FAILED**:
  `left: "/private/var/folders/…/topo_p9_fw_xtree_8161/hooks/security-scan.sh"` (the framework
  worktree's absolute path) vs `right: "${CLAUDE_PROJECT_DIR}/hooks/security-scan.sh"`.

## Resolution (after)

`adapt` now emits the portable form whenever the project root is itself a topology clone, via
`use_portable = !roots_differ || project_has_root_hooks(write_root)` (`adapt.rs`), where
`project_has_root_hooks` checks for `hooks/skill-activation.sh` + `hooks/security-scan.sh` at the
project root. A cross-tree clone (B has root `hooks/`) now gets `${CLAUDE_PROJECT_DIR}/hooks/<name>`
(= `B/hooks/<name>`, which exists) and no pinned `GATEKEEPER_BIN` → survives deletion of A. The
incident is closed. Vendored/external governed projects (no root `hooks/`) keep absolute paths +
pinned bin — unchanged.

`git-common-dir` equality was rejected: vendored-governed (`<project>/.topology` + `<project>`) is the
same git repo, so a same-repo check would misclassify it as cross-tree and emit
`${CLAUDE_PROJECT_DIR}/hooks/` where the hooks actually live under `.topology/` → breaking governed.
The filesystem invariant (project has root `hooks/`) is exactly what the emitted path depends on.

## --check self-heal (M2)

`adapt --check` on such an artifact (the only known cross-tree artifact, the main clone, is now
roots-equal already-portable).
